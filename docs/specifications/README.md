## Adding Further Documents

When adding new requirement files from client discussions:
- Save revised contracts, statement-of-work (SOW) documents, or feature briefs directly into this folder.
- Recommended naming convention: `YYYY-MM_Document_Title.pdf` (e.g. `2026-10_Vishrea_Feature_Signoff.pdf`).
